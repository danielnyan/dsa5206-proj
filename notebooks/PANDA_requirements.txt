Label/geometry policy
  Use Radboud mask RED channel: 0 background/unknown; 1 stroma; 2 benign;
  3/4/5 malignant epithelium GP3/4/5. Karolinska's 0/1/2 scheme has no GP labels.
  Native level-0, stride-600, full 600x600 tiles; discard partial edge tiles.
  Edges still contribute to whole-slide pattern eligibility. Resize RGB to
  350x350 using Lanczos, then legacy brightness + StainTools Macenko, cache PNG.
  No whole WSI is decoded into a RAM array. Mask scan is blockwise.
  MPP is checked (default accepted range 0.35–0.65); missing/out-of-range metadata
  stops preparation. 600px therefore does not mean identical physical FOV on
  every scanner. The two supplied files have about 0.452 and 0.480 um/pixel.
  The training split is frozen at image/slide level before patch selection.
  Training seeds require a single GP across the slide's mask; validation uses
  single-GP tiles from held-out slides. Patient independence is not established.
  Default caps: 1,000 training and 200 validation candidates per GP class.
  This is a deterministic capped pilot, not all of PANDA. Inspect counts before
  choosing larger caps. Changing caps after preparation requires a fresh output.
  Tile-normalization exceptions are warned and audited; no unnormalized fallback.
  Reader, scale, mask-schema, reference and cache-write failures remain fatal.

Handoff and resumption
  1. CPU notebook: CPU_TASK=inventory. Save Version with output files after it
     finishes normally. If incomplete, attach the saved version as Add Input,
     set PREVIOUS_CPU_OUTPUT to its panda_prepared folder, and run again.
  2. Review inventory_report.json and pilot_plan.json. Set CPU_TASK=prepare,
     resume the same CPU output, and preserve the same parameters. Repeat as
     needed until prepared.json says complete=true AND training_ready=true.
  3. Save that completed CPU version with outputs. Add its output to notebook B;
     point PREPARED_INPUT directly at its read-only panda_prepared folder.
  4. GPU_TASK=benchmark first. Enter actual remaining quota hours. Review the
     deepest-stage GPU fit and runtime estimate. Save the benchmark output.
  5. Attach saved benchmark output via PREVIOUS_GPU_OUTPUT, use GPU_TASK=train,
     START_TRAINING=True. Training writes checkpoint files and state.json.
  6. Save every completed invocation with outputs. To resume, attach the latest
     GPU output and the SAME CPU version. Set PREVIOUS_GPU_OUTPUT accordingly.
  7. After run.json complete=true, GPU_TASK=evaluate produces internal-validation
     predictions and metrics. It is not the PANDA hidden-test/ISUP evaluation.

Time/storage limits
  You reported an 8-hour background cutoff. Both notebooks default to a 6.5-hour
  work deadline measured from cell 1, leaving time for setup/commit/save delays.
  A long library operation/checkpoint cannot be interrupted safely mid-call;
  the cutoff is cooperative, not a guarantee against a forced platform kill.
  GPU checkpoints are periodic (15 minutes) and at epoch ends, with Adam state,
  metric totals and the next-batch cursor. The previous checkpoint is preserved
  during an alternating save. Unsaved in-flight batches can repeat after a kill.
  CPU saves inventory per slide and cache records per tile. On interruption,
  only uncommitted work is redone. Same parameter/data versions are required.
  Local checkpoints do not guarantee Kaggle will publish outputs of a killed
  session. Use successful, normally completed saved versions as durable handoffs.
  Official docs describe up to 20 GB saved output, and a variable weekly GPU
  quota (commonly 30 hours or more), not a universal 100-hour free trial.
  Enter the quota shown in your account. Idle GPU session time may count too.
  CPU cache defaults to an 8 GiB limit; the initial 3,600-tile pilot is smaller.
  Do not also ZIP the cache inside /kaggle/working: that duplicates storage.
  GPU output includes two optimizer checkpoints and a final model; actual sizes
  must be checked on Kaggle before scaling up. The CPU cache stays read-only
  under /kaggle/input, so it is not duplicated in GPU saved output.
